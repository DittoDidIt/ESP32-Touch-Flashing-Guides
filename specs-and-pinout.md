# ⚙️ MaTouch 2.8" (ESP32-S3) Technical Specifications & Pinout

> **Lab:** Ditto Did It Labs

## 📌 Chipset & Core Specs
* **MCU:** Espressif ESP32-S3 (Dual-Core Xtensa LX7, up to 240MHz)
* **Wireless:** 2.4 GHz Wi-Fi (802.11 b/g/n) + Bluetooth 5 (LE)
* **Display Size:** 2.8-inch TFT LCD
* **Resolution:** 240x320
* **Touch Controller:** Capacitive / Resistive Touch (I2C/SPI)
* **Interface Ports:** USB Type-C, Expansion Headers (HY2.0-4P / I2C)
